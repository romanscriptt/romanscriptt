## Áreas de especialización

- **Desarrollo de aplicaciones:** construcción de aplicaciones multiplataforma (web y móvil), desde el modelado de la base de datos hasta la interfaz de usuario, siguiendo metodologías de diseño relacional y buenas prácticas de control de versiones.
- **Ingeniería de Prompts:** técnicas *Few-Shot*, *Chain-of-Thought* e iteración avanzada para LLMs (GPT-4o, Claude).
- **Automatización:** diseño de flujos de trabajo complejos en **n8n** y **Make**, con conexión de APIs y Webhooks para integrar servicios y asistentes de IA en procesos reales.
- **Ciberseguridad en IA:** implementación de *Safety Prompts* contra Prompt Hacking e inyecciones de código.
- **Voz & Audio:** configuración de asistentes inteligentes mediante **VAPI**.

## Proyectos

- Documentación y modelado de bases de datos relacionales (ERD → Modelo Relacional) para casos de gestión empresarial.
- Flujos de automatización en n8n que conectan APIs externas con asistentes basados en LLM.
- Prácticas de desarrollo de aplicaciones multiplataforma en Flutter, integrando persistencia de datos en MySQL.
